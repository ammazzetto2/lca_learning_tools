# LCA Learning Tools

A collection of interactive tools designed to illustrate selected calculations and principles used in agricultural life cycle assessment (LCA).

These tools are intended for learning, teaching, and scientific communication. They allow users to change assumptions and explore how different inputs and accounting methods affect results.

The tools use simplified calculations and illustrative data. They are not connected to the models I use at mywork and do not reproduce its full methodology.

## Available tools

- **Land Use Change Calculation** – Explore how deforestation events are allocated across a 20-year accounting period.

## Disclaimer

These tools are for educational purposes only and should not be used for official environmental assessments.
